# Calle's Construction

[🔴 Live Demo](https://calles-construction.vercel.app) · [🎥 Video Demo](https://www.youtube.com/watch?v=0zUC-XpzIrg)

---

## Español

Sitio web para **Calle's Construction**, una empresa de construcción de varios rubros ubicada en la ciudad de Nueva York.

El sitio permite a los visitantes explorar los trabajos realizados por categoría (rubro), ver la galería de imágenes, consultar la ubicación, y solicitar un presupuesto. Cuenta además con un **modo Admin** completo para que el dueño del negocio pueda gestionar el contenido del sitio sin tocar código: crear, editar y eliminar trabajos e imágenes de la galería, todo desde una interfaz propia.

Para ver todas las funcionalidades y el modo Admin, mirá el **Demo** o escribime pidiendo los datos de acceso.

### Funcionalidades

- 🔐 Login / autenticación para modo Admin
- 🛠️ CRUD completo de **Jobs** (trabajos) y **Gallery** (galería), con carga de imágenes a Cloudinary
- 🔍 Filtro de trabajos por rubro/categoría
- 📍 Ubicación integrada con Google Maps
- 📩 Formulario de contacto / solicitud de presupuesto (EmailJS)
- 📊 Analytics integrado
- 📱 Diseño responsivo, optimizado para mobile, tablet y desktop

### Stack técnico

**Frontend:** React, Sass (Vite)
**Backend / Datos:** Node.js, Express, PostgreSQL
**Servicios:** Cloudinary (imágenes), EmailJS (formularios), Google Maps API, Analytics
**Deploy:** Vercel

### Sobre el desarrollo

Proyecto desarrollado de forma sostenida entre **julio y diciembre de 2024** (con retoques puntuales posteriores), a partir de un diseño UX/UI propio. Incluye más de 200 commits documentando el proceso iterativo: desde la estructura inicial responsive (mobile → tablet → desktop) hasta la implementación completa del modo Admin y la optimización de imágenes y performance.

Gracias por visitar el repo.
Brandon

## English

Website for **Calle's Construction**, a New York City–based construction company with multiple work categories.

The site lets visitors browse completed jobs by category, view the image gallery, check the company's location, and request an estimate. It also includes a full **Admin mode** so the business owner can manage the site's content without touching any code — creating, editing, and deleting jobs and gallery images from a dedicated interface.

To see all the functionalities and the Admin Mode, watch the **Demo** or reach out for access credentials.

### Features

- 🔐 Login / authentication for Admin mode
- 🛠️ Full CRUD for **Jobs** and **Gallery**, with image uploads to Cloudinary
- 🔍 Job filtering by category
- 📍 Location integrated with Google Maps
- 📩 Contact / estimate request form (EmailJS)
- 📊 Integrated analytics
- 📱 Responsive design, optimized for mobile, tablet, and desktop

### Tech stack

**Frontend:** React, Sass (Vite)
**Backend / Data:** Node.js, Express, PostgreSQL
**Services:** Cloudinary (images), EmailJS (forms), Google Maps API, Analytics
**Deploy:** Vercel

### About the development

Built over a sustained period between **July and December 2024** (with occasional refinements afterward), starting from a custom UX/UI design. The repo includes 200+ commits documenting the iterative process — from the initial responsive layout (mobile → tablet → desktop) through the full Admin mode implementation and image/performance optimization.

Thanks for checking out the repo.
Brandon
